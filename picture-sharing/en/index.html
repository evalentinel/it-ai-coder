1. DATA CONTROLLER

For any privacy-related inquiry, users may contact the address provided above.

2. DATA PROCESSED AND PURPOSES

Picture Sharing does not collect, transmit, or store personal data on remote servers. All data remains exclusively on the user's device, stored in a local database (Room DB). No backend servers, corporate infrastructure, or cloud services are involved in any data processing.

The app accesses the following categories of data solely for the local operation of its features:

Approximate location: Used to associate geographic information with images selected by the user and to display location details via the OpenStreetMap/Nominatim service. The location is not transmitted to third parties except to the extent technically required for geocoding requests to Nominatim servers (see Section 5).

Files, photos, and videos: The app accesses the device's external storage to read images selected by the user. No photos or videos are copied, transmitted, or shared without explicit user action.

EXIF metadata and GPS data embedded in photos: The app reads EXIF metadata contained in images in order to extract geolocation information already associated with the photo. Such data is processed locally and is not sent to third parties, except as described in Section 5.

3. LEGAL BASIS FOR PROCESSING

The data processing described above is based on the user's consent (Art. 6(1)(a) GDPR), expressed through the granting of system permissions requested by the app (location access, storage access), as well as on the performance of a contract or pre-contractual measures taken at the request of the data subject (Art. 6(1)(b) GDPR), insofar as the processing is strictly necessary for the features requested by the user.

4. DATA RETENTION

Data processed by the app (file references, associated geographic coordinates, metadata) is stored exclusively in the device's local database (Room DB). The user may delete such data at any time through the app's features or by uninstalling the application, which results in the complete removal of all local data.
